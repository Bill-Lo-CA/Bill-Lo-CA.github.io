Privacy Policy

Effective date: September 18, 2026

2Much2Read is a personal, local-first automation application. It is used by its owner to process selected Gmail newsletters, synchronize Google Calendar information for reminders, and send resulting digests or reminders to a private Discord destination.

Google user data accessed

The application may access Gmail data needed to identify and process configured newsletter messages and Google Calendar data needed to read configured calendars and events. Access is limited to functionality explicitly configured by the user.

How Google user data is used

Gmail content is used to extract and rank newsletter items for a personal digest. Google Calendar data is used to create local agenda and reminder jobs. Google user data is not used for advertising, profiling, or sale.

Storage and processing

OAuth credentials, tokens, configuration, and application databases are stored on the user's own machine. Gmail message bodies are processed for the requested workflow but are not persisted by the application; only limited processing metadata such as hashes and lengths may be retained. Calendar-derived reminder state and digest-related application state may be stored locally in SQLite.

AI processing is local by default through Ollama. If the user explicitly enables a remote Ollama endpoint, email or article content submitted for that processing may leave the local machine and is then subject to the privacy practices of the configured remote service.

Disclosure to third parties

The application sends only the final configured digest, reminder, agenda, or notification output to the user's configured private Discord destination. Those messages are handled by Discord under Discord's own terms and privacy practices. Google user data is not sold.

Data retention and deletion

Runtime data remains on the user's own machine until the user deletes it. The user can remove locally stored OAuth tokens, configuration, and SQLite databases at any time, and can revoke the application's Google access from their Google Account. Discord messages may be deleted through the user's Discord account or server controls.

Security

The application is designed to keep secrets and runtime data outside the public source repository and to restrict local credential and data files with operating-system permissions. No security measure can guarantee absolute protection.

Contact
