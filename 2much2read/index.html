Personal automation project

2Much2Read

2Much2Read is a personal, local-first automation tool that helps its owner process selected Gmail newsletters, schedule reminders from Google Calendar, and deliver final digests or reminders to a private Discord destination.

How it works

Newsletter content is processed locally by default using Ollama. Calendar data is synchronized into local reminder jobs. The application stores runtime state locally and sends only the resulting digest or reminder messages to the configured private Discord destination.

The project is intended for personal use and is not offered as a public commercial service.

Google data access

Google account access is used only to provide the requested Gmail newsletter and Google Calendar automation features. Details about collection, processing, storage, disclosure, and deletion are described in the Privacy Policy.
